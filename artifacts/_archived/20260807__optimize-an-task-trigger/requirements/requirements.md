# 完成标准

## 目标

把"讨论态 → 执行态"的切换从模型隐性理解改为明确、可判定的触发规则，让 an-task 的分流成为必然步骤，并防回归。

## 完成标准

- [ ] AC-1: an-task 的发现描述（description）明确列出“开始/实现/动手/开工/继续按方案做”等进入执行态的触发信号，让隐式调用也能正确命中。
- [ ] AC-2: an-task 正文新增“逐消息重新分流”规则：设计讨论不触发，一旦用户下达开始/实现指令即进入任务分流，前文讨论不构成跳过理由。
- [ ] AC-3: an-init 生成的根 AGENTS 路由要求包含该触发规则，确保初始化后的工作区具备同样的触发语义。
- [ ] AC-4: 契约测试覆盖异常示例（连续讨论后说“开始吧”必须触发 an-task 语义），并验证测试全部通过。
